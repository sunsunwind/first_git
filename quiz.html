C 언어 코드 분석: 포인터와 문자열 배열

💡 핵심 개념:
  • **문자 배열 ($a[]$):** 문자열을 저장합니다. 자동으로 문자열의 끝을 나타내는 **널 문자 ($\backslash 0$)**를 포함합니다.
  • **포인터 ($*p$):** 다른 변수의 **주소**를 저장하는 변수입니다. 여기서는 문자 배열 $a$의 첫 번째 요소의 주소를 저장합니다.
  • **배열 이름 ($a$):** 특별한 경우를 제외하고는 배열의 **첫 번째 요소의 주소**를 나타냅니다.
  • **$a[0]$ vs $a$:** $a[0]$는 배열의 **첫 번째 값**이고, $a$는 배열의 **시작 주소**입니다.
  • **%s vs %c:**
    • $\mathbf{\%s}$는 **주소**를 받아 그 주소부터 **널 문자 ($\backslash 0$)**가 나올 때까지 문자를 **문자열로** 출력합니다.
    • $\mathbf{\%c}$는 **단일 문자** 값을 출력합니다.

🛠️ C 코드

// 초기 코드
char a[] = "Art";
char *p = NULL;
p = a;
int i = 0;
 
printf("%s\n", a);
printf("%c\n", *p);
printf("%c\n", *a);
printf("%s\n", p);
 
for(int i=0; a[i] != '\0'; i++)
    printf("%c", a[i]);

🖥️ 최종 출력 결과

코드를 실행했을 때 터미널에 나타나는 결과입니다:

설명:

  1. 첫 번째 $\mathbf{\%s}$는 배열 $a$의 시작 주소($A$의 위치)부터 $\mathbf{\backslash 0}$가 나올 때까지 읽어 **Art**를 출력합니다.
  2. 두 번째 $\mathbf{\%c}$는 포인터 $p$가 가리키는 값($*p$)인 **A**를 문자로 출력합니다.
  3. 세 번째 $\mathbf{\%c}$는 배열 $a$의 시작 주소($*a$는 $a[0]$와 같음)의 값인 **A**를 문자로 출력합니다.
  4. 네 번째 $\mathbf{\%s}$는 포인터 $p$가 저장하는 주소(배열 $a$의 시작 주소)부터 $\mathbf{\backslash 0}$가 나올 때까지 읽어 **Art**를 출력합니다.
  5. $\mathbf{for}$ 반복문은 배열 $a$의 각 문자를 $\mathbf{\backslash 0}$ 전까지 하나씩 읽어 **Art**를 출력합니다. ($\backslash n$이 없어 한 줄에 이어서 출력됩니다.)
